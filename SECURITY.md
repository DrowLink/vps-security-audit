# Security Policy

## Reporting a vulnerability

Please do not disclose an exploitable vulnerability in a public issue.

Use GitHub's private vulnerability reporting feature for this repository. Include the affected version or commit, reproduction steps, impact, and any suggested mitigation.

Do not include real VPS reports, credentials, private keys, tokens, public IP addresses, or other sensitive infrastructure data.

## Operational safety

Review the script before running it as root. The project is designed to be read-only, but generated reports contain sensitive host metadata and should be stored securely and redacted before sharing.
